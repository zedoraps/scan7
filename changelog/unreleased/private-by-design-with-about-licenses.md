type: feature
created: 2026-10-19T09:38:10.908696Z

Scan7 has no internet access and collects no data. The camera is used only for scanning cards and QR codes, and shared games go only from phone to phone. Tap the version on the start screen for About & licenses: the privacy policy, the source code (AGPL-3.0) and the third-party notices.
